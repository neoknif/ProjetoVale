# 🌐 Projeto Vale

> Projeto web desenvolvido para fins acadêmicos, focado em uma iniciativa comunitária de inclusão social e apoio no Vale do Paraíba.

---

### 🚀 Tecnologias Utilizadas

* **HTML5** (Semântico, Acessível e Aprovado pelo W3C)
* **CSS3** (Variáveis CSS, Design Responsivo, Flexbox e Grid)
* **Vimeo API / Embed** (Player de vídeo institucional integrado sem restrições de CORS)
* **W3C Standards** (Validação completa de marcação e estilos)
* **GitHub Pages** (Hospedagem e deploy contínuo)
