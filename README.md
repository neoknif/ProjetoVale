# Projeto Vale 🌐

Projeto web desenvolvido para fins acadêmicos, focado em uma iniciativa comunitária de inclusão social e apoio no Vale do Paraíba.

## 🚀 Tecnologias
- **HTML5** (Semântico e Acessível)
- **CSS3** (Variáveis CSS, Design Responsivo, Flexbox e Grid)
- **W3C Standards** (Validação completa de marcação e estilos)

## 📁 Estrutura de Arquivos
- `index.html`: Página principal com apresentação institucional e mídia em vídeo.
- `projetos.html`: Listagem de projetos sociais ativos e tabela de doações.
- `cadastro.html`: Formulário de apoio com validações nativas e Regex.
- `css/style.css`: Estilização completa e responsiva do tema Dark.

## ✅ Validação W3C
Todo o código-fonte foi submetido e aprovado pelo *W3C Markup & CSS Validation Service*, atingindo **0 erros e 0 avisos**.
